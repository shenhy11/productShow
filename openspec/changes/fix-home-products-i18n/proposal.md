## 变更原因 (Why)

在前一次的前端重构阶段，我们搭建起了框架骨干与路由基础，但在深度验收过程中发现了以下具体缺陷：
1. **首页缺乏重点视觉牵引**：首页目前缺少产品轮播图，无法直观抓取访问者眼球。
2. **产品中心内容缺失**：进入产品中心或具体分类下时，并没有将爬取好的丰富内容挂载展示在内容区。
3. **国际化 (i18n) 支持不彻底**：通过语言拦切换为“中文”后，依然有大量硬编码的英文内容横亘在组件、首页与面包屑中，翻译并不彻底。
为了解决这些体验类 Bug，我们将参考 `crawl_output` 中的官方资源，补充缺失组件与彻底地实现文本抽取工作。

## 涉及改动点 (What Changes)

- 为首页增加一个具备自动轮播功能的 `ZProductCarousel.vue` 产品焦点图轮播模块。
- 改写并丰富 `product-display` 模块，将 `crawl_output` 中抓取下来的具体产品数据通过模拟库深度注入至产品列表页以及产品详情概览区。
- 实施一次全站范围的硬编码词汇地毯式清除，将 Navbar、Footer、首页推荐模块等位置直接裸露的中文字符串或英文字符串抽取并配置入 `zh.json` 与 `en.json` 翻译池中。

## 能力解构 (Capabilities)

### 新增能力区块
- `home-carousel`: 首页自动轮播产品的交互图集展示功能。
- `i18n-thorough`: 覆盖应用全层级的彻底国际化字典分离绑定支持保障。

### 修改的能力区块
- `product-display`: 全面充实现有的产品中心展现流，结合模拟数据填充实心内容面板。

## 影响面 (Impact)

- 首页模板：`pages/index.vue`
- 多语言核心词典配置：`locales/zh.json`, `locales/en.json`
- UI 组件群：修改并替换硬编码到 `$t()`
- 产品目录页内容层级：`pages/products/index.vue`、`pages/products/[id].vue`
